## Измеренные результаты, не маркетинговая оценка

Для frozen-100 **DEV**, seed 53, оценённого с OpenAI `text-embedding-3-small`, DeepSeek `deepseek-v4-flash`, runtime web OFF, snapshot Qdrant (повтор 20.10.2026):

| Метрика | Значение | Что означает |
|---|---:|---|
| Top-1 hit-any, frozen GOLD v1 | **34/100** | Вернулся один из разрешённых эталоном LD ID |
| Acceptable в широком объединённом пуле | **92/100** | Подходящий по GOLD ID был извлечён до окончательного отсечения |
| Acceptable в top-20 для reranker | **83/100** | Подходящий по GOLD ID дошёл до модели ранжирования |
| Post-hoc top-1, reviewed GOLD v3 | **39/100** | Пересчёт **тех же ответов** после добавления пяти одобренных альтернатив |

Это **не** фактическая точность безопасности выбора, не pass@1 на неизвестном наборе, не промышленные приемочные испытания и не SLA. Пересчёт 34 → 39% **не** означает улучшение pipeline или новый LLM-прогон.

Исторический E08 до current-model replay имел 34% top-1 / 93% wide pool / 84% rerank pool; не смешивайте его стадии с replay (92/83). Источники внутри репозитория: `docs/EXPERIMENTS.md` и `docs/PRODUCT_DECISION_E08_SEED53.md`. Свидетельства по конкретным ID содержат sensitive GOLD и не должны публиковаться без проверки.

## Как трактовать результат

1. **Hit по LD ID не доказывает физическую совместимость.** GOLD может содержать неполные альтернативы или ошибки исходной привязки.
2. **Recall в pool и top-20 не равен точности выбора.** Даже присутствие нужной позиции в кандидатах не гарантирует её первой в ответе.
3. **Нельзя обещать production accuracy.** Требуются зафиксированная версия набора, независимый holdout и end-to-end тест на конфигурации релиза.
4. **Проверка внешними источниками.** Производитель, модель и исполнение могут требовать паспорт/каталог, особенно газовые допуски.

## Инженерная политика

| Параметр | Политика |
|---|---|
| Газ / вода / жидкость | Критичное отличие; liquid-only нельзя предлагать как подтверждённый газовый эквивалент |
| Сертификаты / допуски | `UNVERIFIED` до документального подтверждения; отсутствие данных не означает наличие допуска |
| DN / PN | Учитывать номиналы и единицы, не путать PN16 с 16 МПа |
| Присоединение | Фланцевое, приварное, муфтовое, штуцерное, смешанные исполнения — не считать взаимозаменяемыми без проверки |
| Проход, материал корпуса, привод, исполнение | Существенные ограничения; известный конфликт нельзя маскировать высоким семантическим score |
| Точные обозначения конкурента | Известная точная идентичность не должна превращаться в неподтверждённое семейство |
| Неизвестные атрибуты | `UNKNOWN` / evidence required, а не разрешение на автоматическую замену |

В ограниченной методике ревизии GOLD намеренно **не сравнивались строительная длина и разновидность газа**. Это решение только для scoring; оно не отменяет требования при реальной эксплуатации.

## Текущая зона применения

**Допустимо:** прототипирование, подбор shortlist инженеру, аудит причин ошибок, offline эксперименты на известных данных.

**Недопустимо без независимых процедур:** автоматическая закупка, установка газовой/опасной арматуры по одному LLM ответу, утверждение полной эквивалентности по совпадению названия, публикация маркетинговых процентов без названия benchmark split.

## Перед внешним релизом
